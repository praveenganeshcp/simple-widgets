# Form control

The `sw-form-control` Component is a standalone Angular component designed to enhance the presentation and validation handling of Angular Reactive Form Controls. It acts as a wrapper around input elements, providing features such as label display, error message handling, and dynamic CSS error states based on the input's validation state..

**Inputs**

The Form Control Component takes the following inputs:

1. label: A string representing the label to be displayed for the form control.

2. errorMessagesMap: A map that associates validation error names with corresponding error messages. This map is used to dynamically display error messages based on the input's validation state.

3. control: An instance of Angular's Reactive Form Control. This is the control that manages the input's validation state.

**Usage:**
1. Import the `SwFormControlComponent` into your Angular module.
2. Wrap the `sw-form-control` component around the `input` elements binding it to a `formControl` instance.
3. Pass the form control instance as input to `control` prop, provide the label for the control in
`label` prop and provide the map of custom error message if needed.

**Example:**

```html
 <sw-form-control [label]="label" [control]="control" [errorMessagesMap]="errorMessagesMap">
        <input type="text" sw-input [formControl]="control"  />
</sw-form-control>
```
