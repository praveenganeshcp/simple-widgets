# Switch

**Description:**
The `sw-switch` component is designed to provide a user-friendly switch toggle input for Angular applications. It seamlessly integrates with Angular's `[(ngModel)]` or `formControl` instances, making it as easy to use as other input elements. Users can toggle between `true/false` or `on/off` values.

**Usage:**

1. Import the `SwSwitchComponent` into your Angular module.
2. Implement the `sw-switch` element in your template, binding it to `[(ngModel)]` or a `formControl` instance.
3. Users can interact with the switch control to select between `true/false` or `on/off` values.

**Example:**

```html
<sw-switch [(ngModel)]="isSwitchOn"></sw-switch>
```
