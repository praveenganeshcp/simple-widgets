# Dialog

**Description:**
The `SwDialogService`, provided by the `SwDialogModule`, allows for the easy creation of modal dialogs within Angular applications. Developers can use this service to open modals containing custom components and data.

**Method:**
- `open(componentClass: ComponentType<unknown>, config: {data: any})`: Opens a modal dialog with two arguments:
  - `componentClass`: The class of the custom component to render within the modal.
  - `config`: An object with `data` property, that can hold any data you want to make available within the modal. This data can be accessed inside the modal using the `SW_DIALOG_DATA` injection token.

**SwDialogRef Usage:**
- Once a modal is opened, developers can use the `SwDialogRef` injection token to get a reference to the opened modal. They can call the `close` method on `SwDialogRef` with any value, which will be available to the caller once the modal is closed.
- In the caller side, when the modal is opened, the `open` method will return the same `SwDialogRef` object. Developers can subscribe to the `afterClosed$` property to retrieve the values passed to the `close` method.
- When users click outside the modal, a `null` value will be emitted in the `afterClosed$` observable.

**Example:**

***Modal component:***

```typescript
import { SwDialogModule, SwDialogRef, SW_DIALOG_DATA } from 'ngx-simple-widgets';

@Component({
	standalone: true,
	selector: "sw-dialog-demo",
	template: `<sw-dialog size='sm'>
			<h2>Welcome to {{ data.libName }}</h2>
			<button (click)="closeModal()">close</button>
		</sw-dialog>`,
	imports: [SwDialogModule]
})
class DialogDemoComponent {
	constructor (
		@Inject(SW_DIALOG_DATA) public data: any,
		private dialogRef: SwDialogRef<any>
	) {}

	public closeModal() {
		this.dialogRef.close("Congrats!");
	}
}
```

***Caller:***

```typescript
import { SwDialogModule, SwDialogRef, SwDialogService } from 'ngx-simple-widgets';

@Component({
	standalone: true,
	selector: "sw-dialog-demo-host",
	template: `<button (click)="openDialog()">Open Dialog</button>`,
	imports: [SwDialogModule]
})
class DialogDemoHostComponent {

	constructor(
		private dialog: SwDialogService
	) {}

	public openDialog() {
		const ref: SwDialogRef<any> = 
			this.dialog.open(DialogDemoComponent, { data: { libName: "Simple Widgets" } });
		// prints "Congrats!"
		ref.afterClosed$.subscribe(console.log)
	}
}
```
