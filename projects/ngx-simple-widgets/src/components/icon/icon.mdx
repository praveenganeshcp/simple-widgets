# Icon

**Description:**
The `sw-icon` component is designed to render Material icons easily within Angular applications. It offers a straightforward way to display icons with customizable size options.

**Inputs:**
- `iconName` (string): Specifies the Material icon to render. Only Material icons are supported as of now.
- `size` (string): Defines the size of the rendered icon with allowed values of "sm" (small), "md" (medium), and "lg" (large).

**Usage:**
1. Import the `SwIconComponent` into your Angular module.
2. Implement the `sw-icon` element in your template, providing the `iconName` input to specify the Material icon to display.
3. Utilize the `size` input to adjust the size of the rendered icon.

**Example:**
```html
<sw-icon iconName="home" size="md"></sw-icon>
```
